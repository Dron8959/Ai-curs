# Монтаж Reels / Shorts / брендовых роликов

> Источник знаний: публичные описания уроков канала Justin Odisho (Premiere Pro / After Effects,
> 1,1 млн+ подписчиков, 1500+ уроков) и общие практики short-form-монтажа 2025–2026.
> Видео целиком не просматривались — приёмы описаны по названиям/обзорам уроков и общей
> профессиональной практике. Конкретные цифры (длительность кадра, порог тишины) — ориентиры, не законы.

## Как работать с этим навыком

1. Выясни: платформа (Reels / Shorts / TikTok / YouTube), цель (бренд, личный блог, реклама),
   программа (Premiere Pro, DaVinci Resolve, CapCut), длина, есть ли исходники и музыка.
2. Дай план монтажа по структуре из раздела «Скелет ролика».
3. Для каждого приёма давай шаги для программы пользователя (таблица соответствий ниже).
4. В конце прогоняй «Чек-лист перед публикацией».

## 1. Базовые склейки (основа уроков «5 Essential Cuts»)

| Склейка | Что это | Когда в рилсе |
|---|---|---|
| **Jump cut** | Вырезаем паузы/ошибки внутри одного плана | Говорящая голова — режем всё «э-э», вдохи, тишину > ~0,3 с |
| **J-cut** | Звук следующего кадра начинается раньше картинки | Плавный вход в новую мысль, сцену |
| **L-cut** | Звук текущего кадра продолжается на следующем | Голос за кадром поверх B-roll |
| **Cutaway / B-roll** | Перебивка на другой план, звук основной | Иллюстрировать каждую фразу, прятать джамп-каты |
| **Match cut** | Склейка по форме, движению или цвету | «Вау»-переход между локациями/образами, смена наряда |
| **Cross cut** | Чередование двух параллельных действий | Сторителлинг, «до/после», сравнения |
| **Cut on action** | Режем в середине движения | Динамика, незаметная склейка |

**Premiere:** J/L — выделить клип с Alt (отвязать звук) и сдвинуть край аудио Rolling Edit (N).
**DaVinci:** Ctrl/Cmd+Shift+L — отвязать связь, тянуть край аудио.
**CapCut:** «Извлечь аудио» → сдвинуть дорожку.

## 2. Переходы (самая популярная тема канала — «SAVAGE transitions» для удержания)

Правило: переход должен быть **мотивирован движением в кадре**. Плагины не обязательны,
большинство делается встроенными средствами.

- **Zoom / Punch transition** — масштаб 100→130–200% за 4–8 кадров в конце клипа A и обратный
  в начале клипа B + размытие в движении (Premiere: *Transform* с отключённым *Use Composition
  Shutter Angle*, shutter 180–360; DaVinci: *Motion Blur* в Inspector / Fusion; CapCut: анимация
  «Зум» + «Размытие движения»). Кривая — ease in/out (Bezier).
- **Whip pan / Swish** — быстрый поворот камеры на стыке двух кадров + направленное размытие +
  whoosh-звук. Снимать оба кадра с панорамой в одну сторону.
- **Masking transition** — объект (рука, дверь, столб, человек) перекрывает кадр; маской по краю
  объекта раскрываем следующий клип. Ключ — покадровое отслеживание маски.
- **Before/After wipe** — клип «после» над «до», маска/Crop анимируется слева направо, по краю —
  белая линия или лёгкое свечение. Идеально для бьюти, ремонта, ретуши, продуктов.
- **Color blocking** — кадр заливается сплошным цветом бренда (Color Matte / Solid) с
  анимацией вытеснения, затем открывается новый план. Отлично для брендов — в фирменных цветах.
- **Spin / Roll** — вращение 0→±90° на стыке + motion blur. Сочетается с быстрым битом.
- **Light leak / Flash** — 2–4 кадра белой/цветной вспышки на сильной доле музыки.
- **Glitch / RGB split** — смещение каналов + шум на 3–6 кадров. Для техно/гейминг/дерзкого тона.
- **Speed ramp** — нормальная скорость → резкое ускорение на стыке → замедление на новом плане.

Совет из уроков: **сохраняй удачный переход как пресет** (Premiere: ПКМ по эффектам → *Save
Preset*; DaVinci: сохранить как *Fusion macro / Power Bin*; CapCut: «Мои эффекты»/шаблон), чтобы
не собирать заново. Применяй эффекты к **Adjustment Layer**, а не к каждому клипу.

## 3. Эффекты «как у ниндзя» (Premiere/AE, аналоги в DaVinci/CapCut)

- Клонирование себя в кадре (штатив + маска делит кадр).
- Заморозка кадра + вырезанный персонаж + текст за объектом (text behind subject — тренд).
- Текст, «прилипающий» к объекту (motion tracking).
- Вырезание фона без хромакея (Premiere: *Remove Background* в новых версиях / Roto Brush в AE;
  DaVinci: *Magic Mask*; CapCut: «Удалить фон»).
- Эффект зеркала / калейдоскопа под музыку.
- Монтаж клипа под бит: метки на долях (Premiere: M по ходу воспроизведения; DaVinci: M;
  CapCut: «Ритм»/Beat), склейки и вспышки строго по меткам.

## 4. «Киношный» вид (по уроку «Make Your Videos LOOK CINEMATIC — 6 Easy Steps», 1,3 млн+ просмотров)

1. **Частота кадров / выдержка** — снимать 24/25 fps, выдержка ≈ 1/(2×fps); для slow-mo 50–60+ fps.
2. **Соотношение сторон** — для горизонтали кашетирование 2.39:1 (чёрные полосы); для вертикали
   вместо полос — плотная композиция и малая ГРИП.
3. **Цветокоррекция, затем грейдинг** — сначала баланс белого, экспозиция, контраст (Lumetri /
   DaVinci Color Wheels), потом стиль: тени в холод (teal), тон кожи тёплый (orange), приглушённая
   насыщенность фона. LUT — с интенсивностью 40–70%, не на 100%.
4. **Свет и контраст** — затемнить края (виньетка лёгкая), выделить объект.
5. **Движение камеры / slow-mo** — плавные проезды, замедление ключевых моментов.
6. **Звук и текстура** — плёночное зерно (слабо), саунд-дизайн, атмосфера.

## 5. Скорость работы (уроки «Edit Faster», «5 Editing Mistakes»)

- Горячие клавиши: J/K/L (воспроизведение), I/O (вход/выход), Q/W (Ripple Trim к курсору),
  C/V (бритва/выбор), Shift+Delete (Ripple Delete). Назначь свои на частые действия.
- Порядок: черновая сборка → удержание/темп → B-roll → переходы → графика/текст → звук → цвет → экспорт.
- Прокси для тяжёлых 4K/10-bit файлов.
- Шаблоны проекта: готовые дорожки (V1 речь, V2 B-roll, V3 графика, A1 голос, A2 SFX, A3 музыка).
- Частые ошибки: не выровнен звук по громкости, резкий обрыв музыки, переходы ради переходов,
  перекрученный цвет и кожа, текст вне безопасной зоны, неправильные настройки экспорта.

## 6. Скелет трендового Reels / Shorts (15–45 с)

| Время | Блок | Монтаж |
|---|---|---|
| 0–1,5 с | **Хук** | Самый сильный кадр/фраза первым; текст-хук крупно; движение в первом кадре; без логотипа-заставки |
| 1,5–5 с | **Обещание** | Что зритель получит; быстрый джамп-кат, punch-in зум |
| 5–30 с | **Тело** | Смена кадра каждые 1–3 с (B-roll, зум, угол, графика); паттерн-интеррапт каждые ~5–7 с (звук, вспышка, смена фона) |
| финал | **Пэй-офф + CTA** | Результат/вывод; CTA голосом и текстом; по возможности бесшовная петля (последний кадр → первый) |

**Правила темпа:** тишина > ~0,3 с — режем; каждая фраза — новая визуализация; punch-in 110–120%
на акцентах (чередовать с общим планом, чтобы скрыть джамп-каты).

## 7. Субтитры и текст

- Динамические субтитры по 1–3 слова, выделение ключевого слова цветом бренда/акцентом.
- Шрифт жирный без засечек, обводка или подложка; позиция — в центре-ниже-центра,
  **в безопасной зоне** (не нижние ~20% и не правые ~15% экрана — там UI Reels/TikTok).
- Автосубтитры: Premiere *Speech to Text*, DaVinci *Create Subtitles from Audio* (Studio),
  CapCut «Автосубтитры» — **всегда вычитывать вручную**.
- В CapCut с 2025 автосубтитры могут быть Pro-функцией или иметь лимит на бесплатном плане
  (зависит от региона/версии). Бесплатные обходы: Instagram Edits / стикер «Субтитры» в Reels,
  авто-субтитры TikTok, .srt из YouTube Studio (загрузить ролик «по ссылке») или локальный
  Whisper → импорт .srt в монтажку.

## 8. Звук (половина «дорогого» ощущения)

- Голос: шумоподавление, EQ (срез ниже ~80 Гц), компрессия; громкость диалога около −14 LUFS
  интегрально для соцсетей, пики не выше −1 dBTP.
- Музыка под голос: ducking (−12…−20 дБ под речью).
- SFX на каждый переход, появление текста, зум: whoosh, pop, click, riser, hit.
- Трендовый звук платформы — накладывать в приложении (лицензия), а не вшивать в файл.

## 9. Брендовый монтаж — отличия от личного

- Бренд-кит: 2–3 цвета, 1–2 шрифта, лого, анимация плашек — один шаблон на все ролики.
- Color blocking и плашки в фирменных цветах; цвет продукта — точный (сверить с референсом).
- Продукт в кадре в первые 3 секунды; выгоды через текст, а не только голос (смотрят без звука).
- Никакой чужой музыки/шрифтов без лицензии; для рекламы — коммерческие стоки.
- Готовить версии: 9:16 (Reels/Shorts/TikTok), 4:5 (лента), 1:1, 16:9 + варианты хуков для A/B.
- Сдавать: исходник проекта, экспорт без текста (clean), SRT-файл субтитров.

## 10. Экспорт

- 9:16 — 1080×1920, H.264, 25/30 fps (или как снято), битрейт 15–20 Мбит/с, AAC 320 кбит/с, 48 кГц.
- YouTube 16:9 — 1920×1080 или 3840×2160, VBR 2-pass.
- Без чёрных полос в вертикали; проверить на телефоне перед публикацией.

## 12. Чек-лист перед публикацией

- [ ] Хук в первые 1,5 с, в первом кадре есть движение
- [ ] Нет пауз > 0,3 с и «пустых» кадров дольше 3 с
- [ ] Каждый переход мотивирован и озвучен SFX
- [ ] Субтитры вычитаны, в безопасной зоне, читаемы без звука
- [ ] Громкость выровнена, музыка не перекрывает голос, нет обрыва в конце
- [ ] Цвет кожи естественный, цвет продукта/бренда точный
- [ ] CTA есть; концовка по возможности зациклена
- [ ] Экспорт 1080×1920, проверено на телефоне
- [ ] Для бренда: версии форматов, clean-версия, SRT, лицензии на музыку/шрифты

## Упражнения для прокачки (по 1 в день)

1. Нарезать 60 с говорящей головы в 30 с без единой паузы (jump cut + punch-in).
2. Собрать 3 перехода: zoom, whip pan, masking — и сохранить как пресеты.
3. Before/After wipe на любом преображении.
4. Клип 15 с строго под бит (метки + склейки + вспышки).
5. Разобрать вирусный рилс покадрово: записать время каждой склейки, текста, SFX — и повторить.
6. Брендовый ролик для вымышленного продукта в 3 форматах с бренд-китом.
7. Грейдинг: один и тот же ролик в 3 стилях (тёплый lifestyle, холодный tech, плёночный).

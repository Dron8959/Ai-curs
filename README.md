# msl-edit — монтаж рекламных роликов Make Show Lab

Один JSON → все варианты роликов: хуки × форматы, со вшитыми субтитрами,
экранными карточками, переходами, b-roll и нормализованным звуком.

Проверено: 2 хука × 2 формата собрались за 3 минуты из трёх исходников.
В `sample/` лежат два готовых ролика с тестового материала — посмотри, как
ложатся карточки и субтитры в safe-зоне.

## Что ставить (один раз)

```bash
# 1. ffmpeg — движок всего
brew install ffmpeg          # mac
# или: winget install ffmpeg  (windows), apt install ffmpeg (linux)

# 2. шрифт для карточек (любой жирный гротеск; в скрипте по умолчанию Poppins)
#    скачать с Google Fonts и установить в систему

# 3. субтитры из речи, локально
pip install faster-whisper
```

Claude Code: открыть папку проекта, и всё — дальше просишь словами
(«собери A1 с хуком 6 в 9:16», «сдвинь карточку на секунду позже»),
я правлю edit.json и запускаю сборку.

## Рабочий цикл

```bash
# 1. что наснимали
python3 msl_edit.py probe ./footage

# 2. субтитры из речи (по файлу на каждую дорожку)
python3 transcribe.py footage/anna_body.mp4 --out subs/body.srt --lang en --words 4

# 3. собрать все варианты
python3 msl_edit.py build edit.json --out ./render

# 4. ревью: лист кадров, чтобы я посмотрел композицию
python3 msl_edit.py contact render/a1_hook2_9x16.mp4 --every 2
```

## edit.json

`edit.example.json` — рабочий пример. Поля:

| поле | что делает |
| --- | --- |
| `formats` | `9x16`, `4x5`, `1x1` — кроп по центру + safe-зоны под каждый |
| `body` | куски основного тела: файл, `in`, `out`, `transition` |
| `hooks` | список хуков; каждый даёт отдельный ролик с общим телом |
| `body_cards` | экранные карточки тела; тайминги от начала тела, сдвиг под хук считается сам |
| `body_srt` | SRT на тело; сдвигается под длину каждого хука автоматически |
| `broll` | вставки поверх (экран, руки) с `start`/`end`/`scale`/`y` |
| `style` | шрифт и размеры субтитров и карточек |

Переходы — любые из ffmpeg xfade: `fade`, `wipeleft`, `slideup`,
`circleopen`, `dissolve`. По умолчанию жёсткая склейка, и в UGC это чаще
правильно: переход на каждой склейке выдаёт шаблон.

## Safe-зоны (вшиты в скрипт)

| формат | размер | верх | низ |
| --- | --- | --- | --- |
| 9x16 | 1080×1920 | 230 px | 480 px |
| 4x5 | 1080×1350 | 120 px | 200 px |

Карточки садятся под верхнюю границу, субтитры — над нижней. Ничего не
уезжает под интерфейс Reels и под CTA объявления.

## Чего скрипт не делает

- Не выбирает дубли. Какой дубль живой — решаешь ты, глядя и слушая.
- Не ставит тайминги склеек за тебя. Сначала собери тело руками один раз,
  запиши `in`/`out` — дальше все вариации штампуются отсюда.
- Не цветокорит. Снимай ровным светом, по чек-листу.

Ценность не в том, что он режет. В том, что из одного тела он выдаёт
8 вариаций × 2 формата с одинаковой типографикой за один запуск, и когда
через 3 недели креативы выгорят, следующая партия собирается правкой JSON,
а не повторным монтажом руками.

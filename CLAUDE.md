# Make Show Lab

Репозиторий курса Make Show Lab (makeshowlab.com): ИИ-творчество для детей 6–14 лет вместе с родителем.
В корне лежит старая версия лендинга (`index.html`), вся работа над соцсетями — в `social/`.

## Отдел соцсетей
Работа разделена на отделы, по одному на площадку. Если сессия называется «Соцсети · <площадка>», она ведёт
только эту площадку. Перед работой прочитай:
1. `social/desks/README.md` — общие правила отдела и кто за какие файлы отвечает;
2. `social/desks/<площадка>.md` — зона, что готово, правила площадки, что ждёт решения.

## Правила для любой сессии
- Владелец пишет по-русски: отвечай по-русски, простыми словами. Тексты постов — на английском, для родителей в США.
- Факты в постах только из `social/brand/facts.md` и с живого сайта. Ничего не выдумывать: ни историй, ни цифр,
  ни отзывов. Отзывы цитируются дословно, с пометкой, что семьи получили курс бесплатно.
- Голос бренда: `social/brand/voice.md`. Без длинных тире, без рекламных штампов.
- Ничего не публиковать и не ставить в Metricool без прямого «ок» владельца. Работа идёт по этапам: сначала
  показать, потом утвердить, потом делать для всех.
- Старые посты и черновики (`social/posts`, `social/reels`, четыре старых черновика в Metricool) не трогать.
- Git: все отделы работают в одной ветке `claude/pensive-allen-86govc`. Перед работой `git pull --rebase origin claude/pensive-allen-86govc`,
  после работы коммит и `git push`. Pull request не создавать, пока владелец не попросит.
- Почта владельца — личные данные: не отправлять её во внешние сервисы.

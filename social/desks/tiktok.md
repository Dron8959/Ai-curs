# Отдел: TikTok

Лента: видео. Общие правила отдела: `social/desks/README.md`.

## Зона
блок `tiktok` каждого поста в `platforms.mjs`, слайды `posts/<id>/tiktok/`, файлы `posts/<id>/tiktok.md` (всё в `social/concept/`).

## Что готово
- подписи TikTok ко всем 10 постам
- слайды 9:16 для трёх каруселей (фото-режим)
- текст профиля в `PLATFORMS.md`, раздел 5

## Правила площадки, по которым пишем
- подписчики почти не влияют на охват: каждое видео показывают незнакомым, решают досмотр и повторный просмотр
- подпись — это поиск: первые ~100 знаков начинаются с фразы, которую набрал бы родитель
- 2–4 тега по теме, без #fyp; комментарии, Duet и Stitch включены
- отметка «Your brand» включена; отметка ИИ для постов 1, 4, 7, 10
- судить по десяткам видео, а не по одному; ритм 3–5 в неделю

## Как пересобрать
```
node social/concept/render.mjs static   # пишет tiktok.md и слайды 9:16, проверяет, что подпись начинается с поисковой фразы
```

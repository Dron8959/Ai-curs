# Отдел: Threads

Лента: текст. Общие правила отдела: `social/desks/README.md`.

## Зона
поле `threads` каждого поста в `text.mjs`, раздел Threads в `text/<id>.md`, посты только для Threads в `threads.mjs`
(→ `text/threads-NN-*.md`), банк первых строк `text/threads-hooks.md`, карточки `threads-cards.mjs` → `text/threads/` (всё в `social/concept/`).

## Концепция (одобрена владельцем 11.11.2026)
«Мама, которая не согласна»: Анна держит твёрдую позицию против общего страха перед ИИ. Тон тёплый и
вежливый, резонанс даёт сама мысль, а не колкость. Про курс почти не говорим, ссылка примерно в одном посте из пяти.
Рубрики (поле `rubric` в `threads`):
- **Unpopular opinion** (пн, ср, пт): позиция, с которой половина родителей не согласна, и вопрос к несогласным.
- **You decide** (вт, сб): спорная ситуация, родители выбирают сторону в ответах.
- **Kamilla says**: настоящие фразы Камиллы. Ждёт записей от Анны, без них не пишем.
Граница: спорим с идеей, а не с людьми; не пугаем; факты только из `facts.md`.

## Картинки (решение владельца 11.11.2026)
- В Threads **никаких фото Ани и Камиллы и ничего изнутри курса**. Только моушн-графика, нарисованная кодом
  в фирменных цветах (`kit.mjs`), с надписью на карточке.
- Генератор: `node social/concept/threads-cards.mjs [id]` → `text/threads/<id>.mp4` (7 с, 1080×1350, без звука)
  и `<id>.jpg` (последний кадр). Поле `media` в блоке `threads`; поле `image` у поста остаётся за X.
- Голос Ани и Камиллы запишем позже.

## Что готово

- 6 постов только для Threads по этим формулам (`threads.mjs`), карточки к ним ещё не нарисованы
- моушн-карточки для постов 1–5 (`text/threads/`)
- 12 постов Threads переписаны под концепцию (у каждой идеи есть и вариант для X, его не трогали)
- аккаунт подключён к Metricool
- скиллы в `.claude/skills/`: набор blacktwist `*-sms` (стратегия, хуки, посты для Threads) и `last30days`
  (поиск, о чём спорят за последние 30 дней). Справка о бренде для них: `.agents/social-media-context-sms.md`
- last30days в этом облаке пока не видит Reddit: сеть отвечает 403. Нужно разрешить reddit.com в окружении
  или дать ключ ScrapeCreators (он же открывает поиск по Threads)

## Правила площадки, по которым пишем
- площадка про разговор: отвечать нужно больше, чем постить
- до 500 знаков, тёплый тон, в конце настоящий вопрос
- одна тема на пост (ставится в приложении), без хэштегов; ссылка может стоять в тексте
- картинка помогает; колкости и «напиши ДА в комментариях» режутся
- ритм 3–5 постов в неделю, не больше трёх в день; результат копится 60–90 дней

## Как пересобрать
```
node social/concept/text.mjs           # общие посты Threads + X, проверяет лимиты, пишет text/*.md
node social/concept/threads.mjs        # посты только для Threads по формулам из text/threads-hooks.md
node social/concept/threads-cards.mjs  # моушн-карточки (нужны npm install в concept/ и engine/)
```

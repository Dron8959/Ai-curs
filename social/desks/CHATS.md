# Отдел соцсетей в чатах claude.ai

В чатах отдел делается как **проект**: общие знания и правила один раз, внутри по чату на площадку.
Создать проект из Claude Code нельзя, это делается руками за пять минут. Всё нужное ниже.

Чем чат отличается от диалога в Claude Code: в чате удобно обсуждать, придумывать и писать тексты, но он
не меняет файлы и не собирает картинки и ролики. Готовый текст из чата нужно отнести в диалог того же
отдела в Claude Code: там он попадёт в репозиторий и в сборку.

## 1. Создать проект
Проекты → Новый проект.
- Название: `Соцсети Make Show Lab`
- Описание: `Отдел соцсетей: Instagram, TikTok, Facebook, YouTube Shorts, Threads, X, Pinterest`

## 2. Вставить инструкции проекта
```
Ты работаешь в отделе соцсетей курса Make Show Lab (makeshowlab.com): ИИ-творчество для детей 6–14 лет
вместе с родителем. В проекте семь чатов, по одному на площадку. Название чата — это площадка, которую ты
ведёшь в этом чате: работай только с ней.

Перед ответом сверься со знаниями проекта: CLAUDE.md, social/desks/README.md и файл своей площадки
в social/desks/.

Правила:
- Отвечай по-русски, простыми словами. Тексты постов пиши на английском, для родителей в США.
- Факты только из social/brand/facts.md. Ничего не выдумывай: ни историй, ни цифр, ни отзывов.
  Отзывы цитируй дословно и с пометкой, что семьи получили курс бесплатно.
- Голос бренда: social/brand/voice.md. Без длинных тире и рекламных штампов.
- Соблюдай правила своей площадки из файла отдела: лимиты, где стоит ссылка, сколько тегов.
- Ты не публикуешь и не меняешь файлы. Готовый текст отдавай так, чтобы его можно было перенести
  в диалог этого же отдела в Claude Code.
- Если просьба относится к другой площадке, скажи, в какой чат с ней идти.
```

## 3. Добавить знания
Добавить содержимое → GitHub → репозиторий `Dron8959/Ai-curs`, ветка `claude/pensive-allen-86govc`.
Отметить:
- `CLAUDE.md`
- `social/desks/` (вся папка)
- `social/brand/facts.md`, `voice.md`, `brand-profile.md`
- `social/concept/PLAN.md`, `PLATFORMS.md`
- `social/concept/text/` и `social/concept/pins/` (только файлы `.md`)
- в `social/concept/posts/` файлы `caption.md`, `tiktok.md`, `youtube.md`, `facebook.md`

Если GitHub к claude.ai не подключён, эти же файлы можно загрузить вручную. После каждой большой работы
в Claude Code нажимайте «Синхронизировать», чтобы чаты видели свежую версию.

## 4. Создать семь чатов
Внутри проекта создайте чаты и назовите их по площадкам. Первое сообщение в каждом:

| Чат | Первое сообщение |
|---|---|
| Instagram | Ты ведёшь Instagram. Прочитай social/desks/instagram.md и скажи коротко, что готово и что ждёт моего решения. |
| TikTok | Ты ведёшь TikTok. Прочитай social/desks/tiktok.md и скажи коротко, что готово и что ждёт моего решения. |
| Facebook | Ты ведёшь Facebook. Прочитай social/desks/facebook.md и скажи коротко, что готово и что ждёт моего решения. |
| YouTube Shorts | Ты ведёшь YouTube Shorts. Прочитай social/desks/youtube-shorts.md и скажи коротко, что готово и что ждёт моего решения. |
| Threads | Ты ведёшь Threads. Прочитай social/desks/threads.md и скажи коротко, что готово и что ждёт моего решения. |
| X | Ты ведёшь X. Прочитай social/desks/x.md и скажи коротко, что готово и что ждёт моего решения. |
| Pinterest | Ты ведёшь Pinterest. Прочитай social/desks/pinterest.md и скажи коротко, что готово и что ждёт моего решения. |

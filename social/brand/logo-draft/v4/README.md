# Логотип makeshowlab — версия 4 (на утверждении, к постам и роликам не применена)

Аня и Камилла за ноутбуком, в языке исходного логотипа с роботом: тёмная обводка, жёлтое кольцо,
мятные и коралловые акценты, искры. На крышке ноутбука мятная искра (знак ИИ); такие же искры вылетают
за кольцо: «сделал → показал».

## Файлы
| Файл | Что это | Где использовать |
|---|---|---|
| `logo-horizontal-dark.svg/.png` | значок + надпись + строка, для тёмного фона | сайт, шапки, презентации |
| `logo-horizontal-light.svg/.png` | то же для светлого фона | документы, светлые страницы |
| `logo-stacked-dark.svg/.png`, `logo-stacked-light.svg/.png` | вертикальный вариант | финальный кадр ролика, квадратные места |
| `plate.svg/.png` | логотип на собственной тёмной подложке | верх ролика, поверх фото и видео |
| `avatar.svg`, `avatar-1080.png` | аватар для Instagram, Facebook, Threads | профиль |
| `icon.svg/.png` | значок с искрами | отдельно от надписи, от 96 px |
| `icon-plain.svg` | значок без искр, по границе кольца | плашка, тесные места |
| `icon-small.svg/.png` | упрощённый рисунок: толще линии, без мелких деталей | 64 px и меньше, фавикон |
| `wordmark-dark.svg`, `wordmark-light.svg` | только надпись, в кривых | где значок не нужен |
| `logo-system.jpg`, `reel-mock.jpg` | листы для показа | — |

## Правила размера
- Основной рисунок читается от 96 px по ширине значка. На ролике 1080×1920 плашка ставится со значком 128 px.
- 64 px и меньше — `icon-small`.
- Плашку на ролике держать ниже 250 px от верха: выше её перекрывает интерфейс Instagram, а в ленте
  ролик обрезается по центру. Сейчас в движке логотип стоит на 110 px — при переносе сдвинуть.

## Цвета и шрифты
Navy `#141A33` · Yellow `#FFC533` · Coral `#FF6F4A` · Mint `#5FE0A8` · Cream `#FFF4DC`.
На светлом фоне жёлтый и коралловый в надписи темнее: `#F2A200`, `#F25C36`.

Надпись — Sora ExtraBold, трекинг −40, буква `l` заменена на простую стойку (в шрифте она с флажком
и читается как «1»: show1ab). Строка — Urbanist Bold, разрядка подобрана под ширину надписи.
Оба шрифта под лицензией SIL OFL 1.1, для логотипа и коммерции свободны. В SVG текст переведён в кривые,
шрифты для показа не нужны.

## Как пересобрать
```bash
python3 make_icon.py                 # icon.svg, icon-small.svg, avatar.svg, icons.json
node build.mjs <папка-со-шрифтами>   # надпись в кривые и все варианты логотипа
node render.cjs logo-horizontal-dark.svg logo-horizontal-dark.png 2400
node sheets.cjs <кадр-ролика.png> <фото.jpg> .   # листы logo-system и reel-mock (потом в JPG)
```
Папка со шрифтами: `npm i opentype.js @fontsource/sora @fontsource/urbanist` в любой пустой папке.
`icon-plain.svg` собирается из `icons.json` (ключ `plain`, рамка 912×912 вокруг центра кольца).

## После утверждения
1. Скопировать итог в `social/media/brand/` и переключить `logoSrc()` / `brandChip()` в `social/engine/kit.mjs`.
2. В `reel.mjs` заменить верхнюю строку бренда на плашку и опустить её и заголовки сцен ниже 250 px.
3. Пересобрать 12 каруселей и 7 роликов, обновить 4 черновика в Metricool.
4. Поставить аватар в трёх сетях (вручную), обновить превью профиля.

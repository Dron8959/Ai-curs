# Логотип makeshowlab — утверждённый набор

Аня и Камилла за ноутбуком. Утверждено 10.11.2026. К существующим постам и роликам пока не применено:
движок (`social/engine`) до следующего этапа берёт старые файлы из `social/media/brand/`.

## Что где
| Папка | Что внутри | Куда |
|---|---|---|
| `avatar/` | `avatar-1080.png`, `avatar.svg` | фото профиля в Instagram, Facebook и Threads |
| `reels/` | `plate.png`, `plate@2x.png`, `plate.svg` — плашка; `end-logo.png`, `end-logo.svg` — вертикальный логотип | плашка стоит на каждом будущем ролике; вертикальный логотип закрывает ролик |
| `logo/` | горизонтальный и вертикальный логотип для тёмного и светлого фона, надпись отдельно, значки, персонажи | сайт, документы, обложки, оформление |
| `sheets/` | `logo-system.jpg`, `reel-mock.jpg` | листы для показа |
| `src/` | исходники: рисунок значка и сборка | пересборка |

## Правила
- **Аватар.** Значок с искрами на тёмно-синем. Искры сдвинуты внутрь круга, по которому соцсети обрезают фото.
- **Плашка на ролике.** Кадр 1080×1920: `plate.png` без масштабирования (значок 128 px), левый край 64 px,
  верх не выше 250 px — выше её перекрывает интерфейс Instagram.
- **Конец ролика.** `end-logo` по центру, ширина 650–750 px. Строка под надписью здесь крупнее, чем в
  горизонтальном логотипе, чтобы читалась на телефоне.
- **Мелкие размеры.** От 96 px — `icon`; 64 px и меньше — `icon-small` (толще линии, без мелких деталей).
- **Светлый фон.** `logo-horizontal-light`, `logo-stacked-light`, `wordmark-light`: «make» тёмно-синее,
  жёлтый и коралловый темнее (`#F2A200`, `#F25C36`).

## Цвета и шрифты
Navy `#141A33` · Yellow `#FFC533` · Coral `#FF6F4A` · Mint `#5FE0A8` · Cream `#FFF4DC` · фон аватара `#070A1F`.

Надпись — Sora ExtraBold, трекинг −40, буква `l` заменена на простую стойку (в шрифте она с флажком и читается
как «1»). Строка — Urbanist Bold, разрядка подобрана под ширину надписи. Оба шрифта под SIL OFL 1.1.
В SVG текст в кривых, шрифты для показа не нужны.

## Персонажи
`logo/char-anna.svg` и `logo/char-kamilla.svg` — те же Аня и Камилла отдельно, для постов и роликов.

## Пересборка
```bash
mkdir /tmp/fonts && (cd /tmp/fonts && npm init -y && npm i opentype.js @fontsource/sora @fontsource/urbanist)
social/brand/logo/src/build.sh /tmp/fonts
```
Листы: `node src/sheets.cjs <кадр-ролика.png> <фото.jpg> sheets` (нужен `npm install` в `social/engine`).
